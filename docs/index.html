Unit Converter

Theme: Unit Converter (Python + pytest)

Team

  • Mohamed Amine Bouamri (Nietzsche-god): length and weight conversion
  • Myriam qadri (Mimou777): temperature and volume conversion

Implemented features

  • Length conversion (m, km, cm, mile, foot, inch)
  • Weight conversion (kg, g, lb, oz)
  • Temperature conversion (C, F, K)
  • Volume conversion (l, ml, gallon, cup)

How to run

git clone https://github.com/Nietzsche-god/unit-converter.git
cd REPO_NAME
pip install -r requirements.txt
python -m pytest -q
